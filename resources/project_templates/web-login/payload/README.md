# Plantilla ELIA — Login web (Sauce Demo)

Este proyecto demo incluye un escenario Behave ejecutable sin grabación previa.

## Ejecutar

1. En ELIA → Automatización UI, selecciona este proyecto.
2. Pulsa **Ejecutar Behave** con `features/demo_login.feature`.
3. Revisa el PDF en `outputs/pdfReports/`.
